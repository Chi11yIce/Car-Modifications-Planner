# ModMatch: Car Modification Planner

## Project Goal
Car enthusiasts often spend hours searching forums and websites to determine which modifications are compatible with their vehicle and worth the cost. This project helps users find recommended modifications based on their vehicle, budget, and performance goals.

## MVP Scope
The MVP will:
- Accept a vehicle model from the user
- Accept a budget
- Accept a performance goal
- Recommend compatible modifications
- Display costs and remaining budget

## Future Plans
- Estimate horsepower gains
- Save and load build plans
- Support additional vehicle platforms
- Expand the modification database
